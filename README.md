# Sarbon Cargo Dispatcher

Frontend test task for redesigning dispatcher cargo list page.

## Tech stack

- Next.js
- React
- TypeScript
- React Query
- Axios
- Tailwind CSS
- shadcn/ui

## Features

- Cargo list page
- API integration with required headers
- Pagination
- Limit selector: 10 / 20 / 50
- Search filter
- Loading skeleton
- Error state
- Empty state
- Responsive design
- UZ / RU / EN language switcher

## Getting started

```bash
npm install
npm run dev
```
